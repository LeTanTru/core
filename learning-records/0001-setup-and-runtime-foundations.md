# 0001: Môi trường sân tập & Nền tảng OS / V8 / Event Loop

Đã thiết lập thành công sân tập `core-practice` với Node.js ESM + Vitest (chạy xanh 100%). Hoàn thành 3 bài lý thuyết nền tảng về Process vs Thread, V8 Memory Management (Generational GC, Reachability) và Thuật toán Event Loop (Call Stack → Microtasks → Render/rAF → Macrotasks).

## Evidence

- Test suite `sanity.test.js` trong `core-practice` chạy pass với Vitest v4.1.10.
- Các bài học 07, 08, 09 đã được cấu trúc chi tiết với interactive quiz, code demo Vitest và interview tips.

## Implications

- Người học đã có nền tảng vững về mô hình bất đồng bộ và bộ nhớ, sẵn sàng mở rộng sang Promise Internals, DOM/Browser Rendering, Networking và Web Security.
- Lộ trình tổng thể cần mở rộng toàn diện (30 bài phân bổ trong 8 modules) để bao phủ trọn vẹn toàn bộ kiến thức Frontend Intern cốt lõi.
