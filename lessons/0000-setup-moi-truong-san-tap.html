Bài 00 · Dựng môi trường sân tập core-practice

Khởi tạo sân tập Node.js + Vitest để tự tay chạy code & kiểm chứng mọi khái niệm IT Core.

⏱ ~10 phút · 🎯 Mục tiêu: Chạy thành công suite test xanh 100% trên máy thật bằng lệnh npm test.

🌉 Vì sao cần Bài 00 trước khi học kiến thức IT Core?

Một trong những sai lầm lớn nhất khi ôn phỏng vấn IT Core là học "chay" (chỉ đọc lý thuyết). Khi phỏng vấn kỹ thuật, nhà tuyển dụng sẽ đưa ra các đoạn code tình huống (Event Loop, Memory Leaks, Scope, Promise chaining). Việc có sẵn sân tập core-practice trên máy giúp bạn thử nghiệm ngay kết quả thực tế bất cứ lúc nào.

1. Kiểm tra tiền đề máy thật

Hệ thống đã dò quét tự động trên máy Windows của bạn và xác nhận các công cụ tiền đề đã sẵn sàng:

Công cụ Trạng thái máy bạn Yêu cầu tối thiểu
Node.js v22.22.2 (Đã sẵn sàng) v18.0.0+
npm v11.4.2 (Đã sẵn sàng) v9.0.0+
Git v2.49.0 (Đã sẵn sàng) v2.0.0+

2. Các bước khởi tạo sân tập (Đã kiểm chứng)

Sân tập core-practice được cấu hình chuẩn ES Modules (ESM) để chạy tốt các cú pháp JavaScript hiện đại nhất.

Bước 2.1: Khởi tạo thư mục và package.json

Tạo thư mục core-practice và thiết lập "type": "module" trong package.json:

bash 
# Tạo thư mục sân tập và di chuyển vào trong
mkdir core-practice
cd core-practice

# Khởi tạo package.json mặc định
npm init -y

Bước 2.2: Cấu hình package.json & Cài đặt Vitest

Cài đặt vitest (phiên bản v4.1.10 đã được verify chạy cực nhẹ và nhanh) làm bộ test runner chính:

bash 
# Cài đặt Vitest làm devDependency
npm install -D vitest

File package.json trong thư mục core-practice đạt chuẩn trông như sau:

json — core-practice/package.json 
{
  "name": "core-practice",
  "version": "1.0.0",
  "type": "module",
  "scripts": {
    "test": "vitest run"
  },
  "devDependencies": {
    "vitest": "^4.1.10"
  }
}
💡 VÌ SAO cần `"type": "module"`?

Trình duyệt hiện đại và Node.js ngày nay dùng ES Modules (cú pháp import / export). Đặt "type": "module" giúp code sân tập hoàn toàn đồng bộ với môi trường trình duyệt thực tế, loại bỏ rào cản CommonJS cũ kỹ (require / module.exports).

3. Sanity Check: Kiểm chứng môi trường

Tạo file sanity.test.js bên trong thư mục core-practice để xác nhận môi trường chạy xanh:

javascript — core-practice/sanity.test.js 
import { expect, test } from 'vitest';

test('Sanity Check: Sân tập core-practice hoạt động bình thường', () => {
  // Kiểm chứng phép tính cơ bản
  expect(1 + 1).toBe(2);
});

Mở terminal trong core-practice và chạy lệnh:

bash 
npm test

Kết quả đầu ra xanh (Pass) thực tế đã được verify trên máy bạn:

🧠 Kiểm tra nhanh (feedback ngay)

Câu 1. Vì sao chúng ta lựa chọn Vitest để làm test runner cho sân tập IT Core thay vì Jest truyền thống?
🎯 Bộ câu hỏi thực tế ôn tập & Phỏng vấn thực chiến
  1. Câu hỏi 1: Tại sao các công cụ Frontend hiện đại (Vite, Vitest, Node.js hiện đại) lại chuyển dịch toàn diện sang ES Modules (ESM) thay vì CommonJS (CJS)?
    Trả lời 60s: ESM sử dụng cú pháp tĩnh (Static Import/Export), cho phép phân tích cú pháp tĩnh (Static Analysis) trước khi chạy code. Nhờ đó, bundler có thể thực hiện Tree-Shaking (loại bỏ code thừa không dùng đến) để tối ưu kích thước bundle và hỗ trợ asynchronous module loading native trên trình duyệt. Trong khi đó, CJS sử dụng require() động tại runtime nên không thể tree-shake hiệu quả.
  2. Câu hỏi 2: Phân biệt vitest (watch mode) và vitest run? Tại sao trong CI/CD bắt buộc phải dùng vitest run?
    Trả lời 60s: Lệnh vitest mặc định bật Watch Mode — tiến trình không thoát mà tiếp tục lắng nghe thay đổi file để test lại nhanh (phù hợp dev local). Lệnh vitest run thực thi toàn bộ test đúng 1 lần và lập tức trả về mã thoát (exit code 0 khi pass, 1 khi fail), giúp pipeline CI/CD (GitHub Actions) biết được bản build thành công hay thất bại để dừng deployment.
  3. Câu hỏi 3 (Tình huống bẫy): Khi cấu hình "type": "module" trong package.json, tại sao lệnh import { add } from './math' lại bị lỗi ERR_MODULE_NOT_FOUND trong Node.js?
    Trả lời 60s: Node.js ESM tuân thủ nghiêm ngặt chuẩn URL/Path của Web Platform: không tự động đoán đuôi mở rộng file (Extension Resolution) hay tìm file index.js như CommonJS cũ. Bạn bắt buộc phải ghi rõ đường dẫn đầy đủ kèm đuôi file: import { add } from './math.js'.
✅ Bạn vừa hoàn thành
  • Xác nhận đầy đủ công cụ tiền đề: Node v22.22.2, npm v11.4.2, Git v2.49.0.
  • Khởi tạo xong sân tập core-practice với cấu hình ES Modules.
  • Chạy xanh thành công npm test với Vitest v4.1.10.
  • Nắm vững bản chất ESM vs CJS và quy tắc import file trong Node.js ESM.
