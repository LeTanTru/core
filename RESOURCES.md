# IT Core Knowledge Resources

## Knowledge

- [MDN Web Docs — Web Standards & Browser APIs](https://developer.mozilla.org)
  Nguồn tài liệu chuẩn chính thức về HTML/CSS/JS, Browser Rendering, Event Loop, HTTP Headers và Web Security.
- [web.dev by Google — Performance & Browser Architecture](https://web.dev)
  Đặc tả chuyên sâu về rendering pipeline, Critical Rendering Path, Web Vitals và caching.
- [javascript.info — The Modern JavaScript Tutorial](https://javascript.info)
  Giải thích bản chất cực kỳ chi tiết về Event Loop, Call Stack, Microtasks vs Macrotasks, Memory Management.

## Wisdom (Communities)

- [r/Frontend](https://reddit.com/r/Frontend)
  Cộng đồng thảo luận kiến thức Frontend, kinh nghiệm phỏng vấn và thực tiễn công nghệ.
